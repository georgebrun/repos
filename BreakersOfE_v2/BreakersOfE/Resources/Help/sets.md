# Sets
> Every set, and how much of it you own.

**View → Sets** shows every release as a tile, grouped (Main Sets, Core Sets, Commander, Masters & Remasters, …), newest first. Each tile shows the year, how many of its cards you own out of the total, and a progress bar. Hover a tile for its value and what's missing.

## Releases
A release keeps a set's family together: the set with its Commander decks, promos, tokens, art series, oversized and front cards. Its tile adds them all up, and a line underneath says what's inside (**Set · Commander · Promos · Tokens**). Click it for the release's page: one tile per part, each with its own owned count and value. A release with just one set opens straight to its cards.

Note: Which set belongs to which release comes from Scryfall, saved by **Update Database**. Until the first update, every set has its own tile.

## A set's cards
Click a set's tile to see its cards. Tokens open in the Tokens table, oversized cards in Oversized, and so on. **Missing Only** shows just the ones you don't own; in the Gallery, cards you don't own are dimmed. The status line shows **Owned X of Y (Z%) · Missing N**. **◀** goes back: to the release's page if you came from one, else to **All Sets**.

Tip: Search on the Sets page finds a release by its name or any of its parts' names ("Forgotten Realms Commander" finds Adventures in the Forgotten Realms).

## Adding a set's cards (Edit → Sets)
**Edit → Sets** has the same tiles and release pages, for adding cards. Open a set and its cards fill the page as pictures, with a **− count +** box under each picture for each finish. There's no collection table underneath: each part goes to its own collection table (a set's cards to **Collection → Cards**, its tokens to **Tokens**, oversized cards to **Oversized**, and so on).

- The bar on top has **Add/Remove Qty**, **Language** and **Condition** for the cards you add, plus **Remove All…** and **Undo**.
- **Missing Only** and the dimmed pictures work here too. A card brightens as soon as you add it.
- **◀** goes back to the release's page or to all sets, with the owned counts updated.

Step by step: [[howto-add-set]].

## Set Completion
**Set Completion** lists every set with how many you own, how complete it is, the set's value and what's missing. **Only sets I own cards from** is ticked to start. Double-click a set to open it.
