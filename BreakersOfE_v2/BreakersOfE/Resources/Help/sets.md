# Sets
> Every set, and how much of it you own.

**View → Sets** shows every set as a tile, grouped (Main Sets, Core Sets, Commander, Masters & Remasters, …), newest first. Each tile shows the year, how many of its cards you own out of the total, and a progress bar. Hover a tile for the set's value and what's missing.

## A set's cards
Click a tile to see that set's cards. **Missing Only** shows just the ones you don't own; in the Gallery, cards you don't own are dimmed. The status line shows **Owned X of Y (Z%) · Missing N**. **◀ All Sets** goes back.

## Set Completion
**Set Completion** lists every set with how many you own, how complete it is, the set's value and what's missing. **Only sets I own cards from** is ticked to start. Double-click a set to open it.
