# Want List
> Edit → Lists → Pool → Want List: cards you're looking for.

The card pool is on top and your Want List below. Each want row is one printing in one finish.

## Using the list
- **Add Non-Foil / Add Foil / Add Etched** ([Enter], [Shift+Enter], [Ctrl+Enter]): put Qty copies on the list.
- **Remove** ([Delete]): take Qty off. [Shift+Delete] removes all of the selected rows.
- **Got It…**: you got the cards. Qty copies go into your collection, in the **Language** and **Condition** picked beside the button, and come off the Want List. Undo takes back both.

## Offer and notes
- **Offer**: what you'd pay per copy. Double-click the Offer cell (or right-click → **Set Offer…**) and type a price like 4.50; leave it empty for none.
- **Notes**: double-click the Notes cell, or right-click → **Edit Notes…**.

Tip: **Find Missing…** on a deck adds what the deck still needs to the Want List in one go. See [[howto-find-missing]].

**Undo** or [Ctrl+Z] takes back the last 20 changes.
