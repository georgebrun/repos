# Want List
> Edit → Lists → Pool → Want List: cards you're looking for.

The card pool is on top and your Want List below. Each want row is one printing in one finish, **for** a deck or for your **Collection** (the **For** column). Several decks can want the same card: each has its own row.

## Using the list
- **For**: who new wants are for: **Collection**, or one of your decks. Pick it before adding.
- **Add Non-Foil / Add Foil / Add Etched** ([Enter], [Shift+Enter], [Ctrl+Enter]): put Qty copies on the list, for the **For** choice. On a want row, **Add more** adds to that row's own want. With both tables in Gallery these buttons (and **Remove**) are hidden: use the − / + boxes under each picture.
- **Remove** ([Delete]): take Qty off. [Shift+Delete] removes all of the selected rows. Remove deletes the want only: nothing in your collection or decks changes.
- **Got It…**: you got the cards. A window asks:
  - **Copies received**: how many arrived.
  - **They're for**: a tick per want, decks first, then the Collection, each with how many it wants (and what the deck is still missing). The copies go to the ticked wants in that order.
  - Every copy goes into your collection, in the **Language** and **Condition** picked beside the button. Copies for a deck are **claimed** for it (up to what the deck still misses); copies for the Collection and **extra copies** stay free. Unticked wants stay on the list.
  - With several rows selected (or **Got It — all of the selected rows**), each row's copies go to its own want, no window.
  - **Undo** takes back all of it: the Want List, the collection and the decks' claims.
- **For ▸** (right-click a want row): move the selected wants to the Collection or another deck.
- **Print Slip…** (right-click): proxy slips of the selected rows, as many as each row wants, to play with until the real cards arrive, if your group agrees. See [[view-and-edit]].

## Offer and notes
- **Offer**: what you'd pay per copy. Double-click the Offer cell (or right-click → **Set Offer…**) and type a price like 4.50; leave it empty for none.
- **Notes**: double-click the Notes cell, or right-click → **Edit Notes…**.

## Adding from other pages
- **Decks:** **Find Missing…** adds what the deck still needs in one go, as wants for that deck ([[howto-find-missing]]). Right-click deck lines → **Add Missing to Want List (for this deck)** does it for just those lines.
- **Collection → Cards:** right-click a card → **Add to Want List (for the Collection)** puts Qty copies on the list.

Wants made before the For column, with "For: Deck name" in their **Notes** (Find Missing used to write that), become wants for that deck the first time you open the Want List. A note naming several decks, or a deck that isn't found, is left as it is: use **For ▸** on those.

Importing into the Want List adds to (or, with Replace, replaces) the **Collection's** wants only; wants for decks are left alone.

**Undo** or [Ctrl+Z] takes back the last 20 changes.
