# Search and Filters
> Jump to a card, or show only the cards you want.

## Search
The **Search:** box at the top of a table looks for card **names that start with** what you type. It selects the first match and scrolls it into view; it never hides rows. In the Sets and Decks pages it jumps to the first set or deck whose name starts with the text.

## Column filters (the funnels)
Each column header has a funnel. Click it to open **Filter: (column)**:
- **Sort A → Z** / **Sort Z → A** sort by that column.
- **Values** tab: tick the values to keep. **Search values…** narrows the list; **(Select All)** ticks them all.
- **Text Filters** tab: pick a test (Contains, Does Not Contain, Equals, Begins With, Greater Than, Is Blank …), type the text and press **Apply** (or [Enter]).
- **OK** ([Enter]) keeps the filter, **Cancel** ([Esc]) doesn't, **Clear** removes it.

A funnel turns the accent color while its column is filtered.

## The Filters panel
Click **Filters** for a panel with everything in one place. While any filter is on, the button reads **Filters (N)**.
- **CARD:** Color (W U B R G, Multi, None), Rarity, Type, **Legal in** a format, Finish, Artist.
- **COLLECTION · SET · DECKS & LISTS:** owned or not; free copies, in use or favorites; one set; in a deck or not; on the Want List or in the Trade Binder.
- **DETAILS:** text in the name or rules, **Keywords** (has all or has any), and ranges for price, mana value, power, toughness and how many you own.

Each table keeps its own filters, and they work the same in Grid and Gallery. **Clear Panel** clears the panel; **Clear All Filters** at the top clears every filter and puts the sort back to Name.

Note: For a double-faced card, a power or toughness range matches if either side is in range.

Tip: The [[keyword-dictionary]] can open the pool or your collection already filtered to one keyword.

## Sorting
Click a column header to sort; click again to reverse. Cards with the same value are ordered by edition, then collector number, then finish. **Edition: Chrono / Edition: A→Z** picks whether editions go by release date or by name. In the Gallery, use the **Sort** list and its ↑ / ↓ button.
