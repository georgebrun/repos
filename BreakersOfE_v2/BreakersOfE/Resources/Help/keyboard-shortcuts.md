# Keyboard Shortcuts
> Every key BoE knows.

## Tables
- [Ctrl] + mouse wheel, [Ctrl+=] and [Ctrl+-]: zoom the grid in and out. [Ctrl+0]: back to 100%.

## Edit pages
- [Ctrl]+click, [Shift]+click: select several rows or tiles.
- [Ctrl+Q]: jump to the Qty box. [Enter] in the Qty box adds.
- [Ctrl+Z]: undo the last change.
- Top table: [Enter] adds the usual finish (non-foil when the card has one), [Shift+Enter] adds foil, [Ctrl+Enter] adds etched. On the Trade Binder page, [Enter] puts the copies in the binder.
- Bottom table: [Delete] removes Qty, [Shift+Delete] removes all of the selected rows.
- Gallery **+** and **−**: hold [Shift] for foil, [Ctrl] for etched.
- In a cell editor: [Enter] saves, [Esc] cancels.

## Deck → Collection
- Deck table: [Enter] uses copies you own, [Delete] frees the claimed copies.
- Collection table: [Enter] uses that row for the deck.

## Windows
- Card window: [←] and [→] go to the previous and next card; [Esc] closes.
- Statistics and Set Completion: [Esc] closes.
- Column filter: [Enter] is OK, [Esc] is Cancel.

## Program Tour
- [→] or [Enter]: next. [←]: back. [Esc]: close the tour.

## Help
- [F1]: Help for the page you're on. It works in the card window, the statistics windows and Set Completion too.
- [Ctrl+F]: search Help. [Backspace]: back to the previous topic. [Esc]: close Help.
