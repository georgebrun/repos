# ═══ Breakers of E — Help topics ═══
#
# This file sets the order of the Help topic list. Lines starting with # are notes.
#   - A line with a file name (something.md) is a topic.
#   - A line without ".md" is a group heading; indent the topics under it by two spaces.
#
# Each topic is a plain text file in this folder. Its first line is the title
# ("# Title"), the next may be a one-line summary ("> summary"). Then:
#   ## Heading               a section heading
#   - item                   a bullet            1. step    a numbered step
#     (two spaces)           a line indented two spaces continues the item above
#   Tip: …  Note: …  Warning: …    a box (Warning is amber: something to watch out for)
#   **bold**    [Ctrl+Z] a key    [[card-pool]] a link to a topic    [[card-pool|your words]]
#   A blank line starts a new paragraph.
#
# After changing a file, rebuild BoE: the topics are built into the app.
