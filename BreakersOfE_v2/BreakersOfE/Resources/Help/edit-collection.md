# Editing Your Collection
> Edit → Pool → Collection: add and remove the cards you own.

Open **Edit**, then **Pool → Collection** and a kind (Cards, Tokens, …). The card pool is on top (as pictures to start) and your collection below (as a grid). Each collection row is one printing in one finish, language and condition.

## Adding
1. Set **Add/Remove Qty** (how many) and pick the **Language** and **Condition** for new cards. They start from Settings → Collection defaults.
2. Select the card in the pool (on top), or a row of your collection to add more of that row.
3. Click **Add Non-Foil**, **Add Foil** or **Add Etched**, or press [Enter], [Shift+Enter] or [Ctrl+Enter]. In the Gallery, click a picture's **+** (hold [Shift] for foil, [Ctrl] for etched).

Only the finishes the printing comes in can be added.

## Removing
- **Remove Non-Foil / Foil / Etched** take away Qty copies.
- **Remove All…** takes away every unused copy of the printing: all finishes, languages and conditions.
- In the collection table, [Delete] removes Qty from the selected rows; [Shift+Delete] removes every unused copy of them.

Note: Copies used by decks or the Trade Binder are never removed. Free them first in the deck ([[decks]]) or the binder ([[trade-binder]]).

## Changing a row
Double-click a cell of a collection row:
- **Qty**: type the exact number (never below the copies in use).
- **Notes** and **Storage**: type text, e.g. where the card is kept.
- **Fav**: mark or unmark a favorite.
- **Finish**, **Language**, **Condition**: pick from a list. This moves copies to the matching row; if the row has more than one free copy, BoE asks how many.

Right-click a row for the same and more: **Set quantity…**, **Change Finish / Language / Condition**, **Edit Notes…**, **Edit Storage…**, **Mark as Favorite**.

## Several cards at once
[Ctrl]+click or [Shift]+click to select several rows. A change then applies to each row, in that row's own finish, after you confirm.

## Undo
**Undo** or [Ctrl+Z] takes back the last change, up to the last 20. Hover the Undo button to see what it will undo. [Ctrl+Q] jumps to the Qty box.

Tip: BoE copies your collection to the Backups folder before the first change each time it starts, and keeps the last 10. See [[data-folder]].
