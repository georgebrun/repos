# Move Your Data Folder
> Step by step: keep your data somewhere else (another drive, a synced folder).

1. Click **Settings** and scroll to **Data folder**.
2. Click **Move…** and pick an empty or new folder.
3. BoE copies everything, checks the copy, then restarts using the new folder.

Your old folder is kept as it was; delete it yourself once you're happy.

**Use Documents\Breakers of E Again** switches back to the default folder (nothing is copied).

Warning: If the new folder is on a drive that isn't always connected, BoE uses the default folder when the drive is missing. See [[troubleshooting]].
